This repository contains materials related to the following article:

> Rossignol, A.F., Wollrab, S. (**2026**). Resource competition between buoyancy-regulating and sinking phytoplankton species along a stratified water column. _Oikos_.

The folder [code](https://github.com/arthur-f-rossignol/article-003/tree/main/code) comprises the `MATLAB` supporting the entire study.

The folder [documents](https://github.com/arthur-f-rossignol/article-003/tree/main/documents) comprises the last version of the preprint and the supplementary information.

The folder [figures](https://github.com/arthur-f-rossignol/article-003/tree/main/figures) comprises the figures of the paper.
